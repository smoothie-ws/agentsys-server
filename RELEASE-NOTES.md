# AgentSys Server 0.1.0

Initial MVP of the independent headless graph platform.

- Public Web API 1.0 (protocol 1), bearer/session authentication and SSE.
- Workflows, Custom Nodes, Script workers, collections, secrets and permissions.
- Durable store format `agentsys.store/1`, graph format `agentsys.text/1`, Library bundle format 1, transaction recovery and conditional writes.
- Independent npm, API specification and container artifacts. Requires Node.js 22+.

Start with a new empty data directory. See INSTALLATION.md and DEPLOYMENT.md.
